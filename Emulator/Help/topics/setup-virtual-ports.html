Virtual COM Ports

The emulator uses virtual COM port pairs to simulate serial devices. Each pair acts as a null-modem cable: SystemControl opens one end and the emulator opens the other.

Pairing Scheme

A simple +100 offset convention keeps the mapping consistent:

  • Control side: COMnn (the same port number the real hardware uses)
  • Emulator side: COM1nn (Control port + 100)

For example, a device on COM21 pairs with COM121 on the emulator side.

Required Port Pairs

Each serial device listed in the emulator configuration needs one pair. For example:

Device Control Port Emulator Port Baud Rate
Serial device A COM21 COM121 38400
Serial device B COM9 COM109 9600

Automated Setup

The easiest way to create all pairs at once:

  1. Open the emulator and switch to the Config tab.
  2. Click the Prepare System button. In addition to creating virtual COM port pairs, this panel also handles loopback IP aliases and firewall rules.
  3. The emulator calls the installed driver's CLI to create each pair listed above.
  4. Verify the results in the Config tab — each device row shows a green link indicator when its pair is present.

Manual Setup — FVSP

If you prefer to create pairs individually, use the FVSP command-line tool rspcli:

rspcli -create bridge --bridge-ports 21,121
rspcli -create bridge --bridge-ports 9,109

Manual Setup — com0com

Use the com0com setupc utility (run as Administrator):

setupc install PortName=COM21 PortName=COM121
setupc install PortName=COM9 PortName=COM109
Warning: com0com requires Windows to be started in test-signing mode (bcdedit /set testsigning on) because its driver is not WHQL-signed. A watermark appears on the desktop while test-signing is active.

Verifying Port Pairs

After creating the pairs, verify them using any of these methods:

  • Device Manager — expand Ports (COM & LPT) and confirm both sides of each pair are listed.
  • Emulator Config tab — each serial device row shows its port status. A green indicator means the port exists and can be opened.
  • Power Sources link status — on the Power Sources tab, connected devices show a solid link icon when the emulator successfully opens its side of the pair.
