Vacuum Devices

This page documents the emulated vacuum-side devices of the Sputter demo system, including their PLC addresses and emulation behavior. The device list comes from HWConf.Emulator.xml of the Sputter project.

Valves

Nine solenoid valves are controlled via PLC marker bits. Each valve is a simple on/off device mapped to a single bit.

Special valve behaviors:

  • A1 — Vent valve with a conductance of 3.0 L/s into the main chamber.
  • Sound — Valve state changes trigger audio feedback in the emulator dashboard (click / hiss for vent valves).

Mass Flow Controllers (MFCs)

Two MFCs regulate process gas flow, each represented by a setpoint/readback float pair in DB1:

MFCSetpointReadbackGasInlet valve
Ar1DB1:160DB1:164ArgonV1
N21DB1:168DB1:172NitrogenV2

The emulator applies a first-order lag filter so that the readback ramps smoothly toward the setpoint over several tick cycles, mimicking the response time of a real MFC.

Turbo Pump

ParameterValue
Command bitMB0.4
Status byteDB1:17 (bits 1–4)
Pump Speed700 L/s
Gate valveGVM
Foreline valveFL
Crossover Pressure0.5 Torr

The turbo pump spins up while its command bit is set. During spin-up the status byte reports accelerating, then at normal speed, with rotation detected while the rotor turns. The pump only reaches the chamber while the gate and foreline valves are open.

All sensor readings include 2% Gaussian noise to simulate real-world measurement variation.

Rotation

Substrate rotation is controlled by a setpoint/feedback pair and an enable bit:

  • Setpoint / feedback: DB1:1974 / DB1:1978
  • Enable: MB30.0

Input Valve — GVM

The main gate valve (GVM) uses inverted logic on its input bit:

  • Address: EB2.6
  • 0 = gate valve is open
  • 1 = gate valve is closed

This matches the physical sensor wiring where the limit switch is normally closed and opens when the gate valve reaches the open position.
