Vacuum Tab

The Vacuum tab is the primary dashboard view, showing the real-time state of the simulated vacuum system including chamber conditions, gas flow, and valve positions.

Main Chamber Panel

Displays the state of the main deposition chamber:

ReadingDescription
PressureChamber pressure in Torr, auto-scaled (e.g. 760, 1.2e-2, 5.0e-6)
TemperatureSubstrate temperature in °C
Turbo PumpTurbo pump running status and speed

Valve Panel

Valves are displayed with color-coded indicators showing their current state. Click on a valve label to manually toggle it.

ColorStateMeaning
GreenOpenValve is energized and open, gas can flow
RedClosed (energized)Valve is energized but in closed position
GrayClosed (de-energized)Valve is de-energized and closed (default state)
OrangeTransitioningValve is changing state (brief transition period)

Status Bar

The status bar at the bottom of the window displays:

  • Mode — current operating mode (Simulation or Log Replay)
  • Tick Count — number of simulation ticks since startup
  • Simulation Time — elapsed simulation time
