Troubleshooting

Port & Connection Issues

"Port not found" or "Port Down" in Power Sources tab

The virtual COM port pair does not exist.

  • Go to Configuration tab → click Prepare System
  • Verify pairs in Device Manager → Ports (COM & LPT)
  • Check that FVSP or com0com is installed

"No Peer" in Power Sources tab

The COM port pair exists but Control software is not connected to the other end.

  • This is normal when Control is not running
  • Start Control software — status should change to "OK"
  • If Control is running but still "No Peer", verify Control's HWConf.xml uses the matching COM port numbers

"S7 connection refused" from Control software

The S7 server cannot bind to its configured IP address.

  • Verify loopback alias exists: ping 192.168.127.208
  • If no reply, create the alias (see Setup → Network Configuration)
  • Check Windows Firewall allows TCP port 102
  • Ensure only one instance of the Emulator is running

Demo power supply not responding

  • Check the configured TCP port (for example 5025) is not blocked by firewall
  • Check the Log Viewer for TCP serial server errors

Simulation Issues

Pressure is not changing

  • Check the Vacuum tab — are any pumps ON?
  • Verify valve states — PP (pre-pump) or GVM (gate main) must be open for pump to evacuate the chamber
  • Check the Log Viewer for physics errors
  • If all valves and pumps are off, pressure will only change due to leak rate (very slowly)

Pressure stuck at base pressure

This is normal behavior — the chamber has reached its ultimate vacuum. To increase pressure:

  • Open a gas valve (V1 or V2) and set an MFC setpoint
  • Open the air release valve (A1) to vent to atmosphere

MFC showing flow but pressure not responding

  • Check that the gas inlet valve for that MFC is open
  • The gas load effect is proportional to flow — small flows (<1 sccm) may produce imperceptible pressure changes

Turbo pump not starting

  • The turbo pump is enabled through its command bit (MB0.4)
  • If chamber pressure is above 0.5 Torr, the turbo is running but not effective — wait for roughing pump to bring pressure down
  • Spin-up takes the configured TurboSpinUpTime from start to full speed

Configuration Issues

"Config not loading" or blank dashboard

  • Check that Configs/EmulatorConfig.xml exists next to the EXE
  • Verify the <HWConfigPath> inside EmulatorConfig.xml points to a valid file
  • Check the Log Viewer for XML parsing errors

Changes to EmulatorConfig.xml not taking effect

  • If running from the build output, the config is copied from Emulator/Configs/ to bin/Configs/ on build
  • Either edit the bin/ copy directly, or edit the source and rebuild
  • Restart the Emulator after config changes

General

"APS System Emulator is already running"

Only one instance can run at a time. Check Task Manager for an existing APS.SystemEmulator.exe process and close it.

"Access denied" on Prepare System

Prepare System requires administrator privileges. Right-click the Emulator and select "Run as administrator", or approve the UAC prompt when clicking Prepare System.

No sound effects

  • Check that the Sound checkbox on the Log Replay tab is checked
  • Verify Windows audio output is not muted
  • Sound only plays on valve/pump state changes — try clicking a valve label on the Vacuum tab
