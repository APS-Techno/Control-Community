Configuration Files

The emulator reads two XML configuration files at startup. Understanding their layout and location is important for customizing device parameters and physics behavior.

EmulatorConfig.xml

This is the emulator's primary configuration file. At runtime it is loaded from Configs/EmulatorConfig.xml relative to the executable directory.

Key Elements

Element / Attribute Purpose
HWConfigPath Absolute path to HWConf.Emulator.xml (the hardware definition used by the emulator)
Engine TickIntervalMs Physics engine tick rate in milliseconds (default 100)
S7Server S7 protocol server settings (bind address, data-block layout)
Serial Virtual COM port assignments for each serial device
TcpSerial TCP-based instrument connections (e.g., PSU1 on port 5025)
Physics noiseStddev Standard deviation of Gaussian noise added to simulated sensor readings (set to 0 for deterministic output)

HWConf.Emulator.xml

Located in the project folder under Configs, this file is a variant of the hardware configuration that SystemControl uses (HWConf.xml). It defines the same device tree — PLCs, valves, gauges, power supplies — but may contain emulator-specific overrides such as adjusted address offsets or disabled devices.

The emulator resolves this file through the HWConfigPath element in EmulatorConfig.xml.

Warning — sync requirement: The emulator loads configuration from the bin/Configs/ directory at runtime, not from the source tree. After editing EmulatorConfig.xml in the source (Emulator/Configs/), you must copy the updated file to bin/Configs/ or rebuild the project so the build system copies it automatically. Running with a stale copy is a common source of “config changes have no effect” issues.

Config Search Order

When the emulator starts, it looks for EmulatorConfig.xml in these locations, using the first one found:

  1. Configs/EmulatorConfig.xml relative to the executable directory (the normal runtime location in bin/Configs/).
  2. EmulatorConfig.xml in the executable directory itself.
  3. The source-tree path Emulator/Configs/EmulatorConfig.xml (development fallback).
