Prerequisites

Before running the APS System Emulator, ensure the following software and system requirements are met.

.NET 10.0 Desktop Runtime

The emulator requires the .NET 10.0 Desktop Runtime (Windows). This is the same runtime used by SystemControl and System Builder.

Verify your installed runtimes from a command prompt:

dotnet --list-runtimes

Look for a line containing Microsoft.WindowsDesktop.App 10.0.x. If it is missing, download the installer from dotnet.microsoft.com and install the Desktop Runtime (not just the base runtime).

Virtual Serial Port Software

The emulator communicates with SystemControl over virtual COM port pairs. One of the following drivers is required:

  • HHD Software FVSP (recommended) — commercial driver with a command-line tool (rspcli) for scripted pair creation. Stable on all Windows versions without special boot modes.
  • com0com (open-source) — free alternative. Requires Windows to be booted in test-signing mode because the driver is not WHQL-signed.
Tip: The Prepare System button on the emulator's Config tab automates all prerequisites — runtime checks, FVSP pair creation, loopback adapter aliases, and firewall rules. You only need the underlying driver installed; the emulator handles the rest.

Administrator Privileges

Elevated (admin) privileges are needed for:

  • Creating virtual COM port pairs (first-time setup)
  • Adding loopback network adapter aliases for PLC and instrument addresses

Once ports and network aliases are configured, the emulator itself runs under a normal user account.

System Requirements

Requirement Details
Operating System Windows 10 or Windows 11 (64-bit)
Runtime .NET 10.0 Desktop Runtime
Memory < 100 MB typical usage
Network Ports TCP 102 (S7 protocol), TCP 5025 and 5026 (SCPI), virtual COM ports
Admin Rights First-time setup only (port pairs and loopback aliases)
