Configuration Tab

The Configuration tab provides a read-only view of the loaded emulator configuration, protocol server status, and device inventory.

Configuration View

Displays the current configuration loaded from EmulatorConfig.xml and HWConf.Emulator.xml, including:

  • PLC addresses and port mappings
  • Serial device COM port assignments
  • TCP server endpoints
  • Physics simulation parameters (chamber volumes, pump speeds)

This view is read-only. To change the configuration, edit the XML files directly and restart the Emulator.

Protocol Status

Shows the running state of each protocol layer:

  • S7 TCP Server — listening status and connected client count
  • Virtual Serial Ports — open/closed state for each COM port pair
  • TCP Serial Servers — listening status for Ethernet-native devices

Device Count

Summarizes the total number of emulated devices by category (valves, MFCs, pumps, sensors, power supplies, motion axes).

Prepare System Button

The Prepare System button creates or verifies the virtual COM port pairs, loopback IP aliases, and firewall rules required by the Emulator. This operation is idempotent — it is safe to click multiple times. It will create any missing port pairs, IPs, and rules, and skip those that already exist. This button requires administrator privileges to modify virtual COM port driver configuration, network settings, and firewall rules.

Reconnect Ports Button

The Reconnect Ports button closes and re-opens all serial port connections. Use this after virtual COM port reconfiguration or if a port becomes unresponsive. Unlike Prepare System, this does not require administrator privileges and does not modify the port driver configuration.
