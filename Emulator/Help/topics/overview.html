APS System Emulator

The APS System Emulator is a protocol-level hardware simulator for the APS vacuum deposition system. It allows the APS System Control software to run without physical hardware by emulating the PLC and the network-attached instruments at the communication protocol level.

What It Does

  • Emulates a Siemens S7-200 PLC via ISO-on-TCP (port 102)
  • Emulates TCP instruments such as the demo LAN power supplies
  • Simulates vacuum physics — chamber pressure, pump curves, gas flow, temperature
  • Provides a live dashboard showing vacuum state, valve positions, MFC flows, power sources, and log messages
  • Supports log replay for playing back recorded deposition cycles

How It Works

The Control software connects to the Emulator using the same protocols it uses with real hardware — no code changes needed. The Emulator listens on the configured TCP endpoints, responding to commands with realistic simulated data.

Control Software
    |
    +-- S7-200 TCP (port 102) -------> S7 Protocol Server
    +-- TCP:5025 (PSU1) -------------> TCP Serial Server
    +-- TCP:5026 (PSU2) -------------> TCP Serial Server

Architecture

The Emulator runs a 100ms tick loop that updates all device states and physics calculations. Protocol layers bridge the simulated devices to the Control software:

  • S7 Protocol Server — ISO-on-TCP for PLC register read/write
  • TCP Serial Server — direct TCP for Ethernet-native instruments
  • Virtual Serial Adapter — COM port pairs via com0com/FVSP, available for serial devices
