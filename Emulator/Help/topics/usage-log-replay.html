Log Replay

Log Replay allows you to play back recorded deposition cycle data through the simulation engine, reproducing the exact sequence of pressures, flows, temperatures, and valve states from a previous run.

Log File Format

Log files are tab-separated text files with the following structure:

RowContent
Row 1Column names (tab-separated)
Row 2Units for each column (tab-separated)
Row 3+Data rows (tab-separated values, one row per time step)

Each data row contains timestamped readings for all logged parameters. The Emulator parses these values and feeds them into the simulation engine at the correct time intervals.

Controls

ControlDescription
BrowseOpen a file dialog to select a log file for replay
PlayStart or resume playback from the current position
PausePause playback at the current position (resume with Play)
StopStop playback and reset to the beginning of the file
SpeedPlayback speed multiplier: 1x (real-time), 2x, 5x, or 10x
SoundCheckbox to enable or disable sound effects during replay

How Replay Works

During replay, the log data is injected directly into the simulation engine, replacing the normal physics calculations. At each simulation tick, the replay system:

  1. Reads the next data row from the log file based on the elapsed replay time
  2. Writes the recorded values into the corresponding device registers (PLC memory, serial device buffers)
  3. Updates the dashboard displays with the replayed values
  4. Fires any sound effects triggered by state changes (if sound is enabled)

The Control software, if connected, receives replayed data through the normal protocol channels and responds as if real hardware were producing those readings. This makes log replay useful for testing Control behavior against recorded scenarios.
