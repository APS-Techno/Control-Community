Port Mapping

The emulator bridges the gap between SystemControl and virtual hardware using TCP listeners and, for serial devices, virtual null-modem pairs. Each emulated serial device occupies a COM port pair: the device port (emulator side) connects to the host port (Control side) through a null-modem driver such as com0com or FVSP.

Framing Modes

Each serial or TCP device uses a framing mode that determines how message boundaries are detected:

Framing Mode Delimiter / Method
CrLf Carriage Return + Line Feed (\r\n)
Cr Carriage Return (\r)
Lf Line Feed (\n)
ModbusRTU 3.5-character silence gap + CRC16
AdditiveSum16 Fixed-length 22-byte frame (20-byte payload + 2-byte big-endian additive sum)
