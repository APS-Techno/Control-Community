Configuration Reference

The emulator is configured by two XML files: EmulatorConfig.xml controls the emulator engine, protocols, physics, and device library paths, while HWConf.Emulator.xml defines individual device attributes inherited from the system hardware configuration.

EmulatorConfig.xml

Root Element

The root <EmulatorConfig> element contains the following child elements:

ElementDescription
EngineSimulation engine settings
ProtocolsContainer for S7Server, Serial, and TcpSerial entries
PhysicsGlobal physics parameters and chamber definitions
DeviceLibrariesPaths to device emulator DLL assemblies

Engine

AttributeTypeDefaultDescription
TickIntervalMsint100Simulation tick interval in milliseconds

Protocols — S7Server

AttributeTypeDescription
plcIdstringLogical PLC identifier (e.g., PLC1)
bindAddressstringIP address to bind (e.g., 192.168.127.208)
portintTCP port (default 102)

Protocols — Serial

One <Serial> entry per virtual serial device:

AttributeTypeDescription
deviceIdstringLogical device identifier matching the device emulator
portNamestringDevice-side COM port (e.g., COM121)
baudRateintSerial baud rate (e.g., 38400)
framingenumFraming mode: CrLf, Cr, Lf, ModbusRTU, AdditiveSum16

Protocols — TcpSerial

One <TcpSerial> entry per TCP-based device:

AttributeTypeDescription
deviceIdstringLogical device identifier (e.g., PSU1)
bindAddressstringIP address to bind (e.g., 127.0.0.1)
portintTCP port (e.g., 5025)
framingenumFraming mode (typically Lf)

Physics

Global physics parameters:

AttributeTypeDefaultDescription
noiseStddevdouble0.02Sensor noise standard deviation (fraction of reading)
ScrollPumpSpeeddouble10Scroll pump speed factor (L/s)
TurboPumpSpeeddouble300Turbo pump speed factor (L/s)

Physics — Chamber

One <Chamber> entry per simulated vacuum volume:

AttributeTypeDescription
idstringChamber identifier (for example Main)
InitialPressuredoubleStarting pressure in Torr
VolumedoubleChamber volume in liters
BasePressuredoubleUltimate achievable pressure in Torr
LeakRatedoubleVirtual leak rate in Torr·L/s
PumpdownTaudoubleCharacteristic pumpdown time constant in seconds

Physics — Deposition

Optional. One <Deposition> element inside <Physics> turns on the film-thickness and reactive-poisoning model. Without it the emulator does not grow a film, does not poison the target, and the discharge voltage is unchanged. See Physics Model for the equations.

AttributeTypeDefaultDescription
reactiveMfcstring(empty)ID of the MFC that supplies the reactive gas (for example N21). Its actual flow drives poisoning. An empty or unknown ID means zero reactive flow.
ratePerAmpfloat1.0Metal-mode deposition rate per discharge current, nm/(s·A)
poisonRatefloat0.00673Target nitridation rate, 1/(sccm·s)
cleanRatefloat0.1Sputter cleaning rate, 1/(A·s)
poisonedRateFractionfloat0.2Rate of a fully poisoned target relative to metal mode
poisonedVoltageShiftfloat100Discharge voltage increase at full poisoning, V
<Physics>
  <Deposition reactiveMfc="N21" ratePerAmp="1.0" poisonRate="0.00673" cleanRate="0.1"
              poisonedRateFraction="0.2" poisonedVoltageShift="100" />
</Physics>

DeviceLibraries — Library

AttributeTypeDescription
pathstringRelative or absolute path to a device emulator DLL assembly

HWConf.Emulator.xml

This file mirrors the structure of the system HWConf.xml used by SystemControl, with emulator-specific overrides. Key attributes on device elements include:

AttributeTypeDescription
Element textstringDevice ID, such as V1, SP1 or pm
hwtype on the sectionstringDriver type, such as Vendor.S7200Sensor
speeddoublePump speed in L/s
portstringCOM port or TCP address for serial devices
baudrateintSerial baud rate
conductancedoubleVent conductance in L/s
ventboolMarks an atmosphere vent valve

Pressure Measurements and Simulation Time

Sensor attributeMeaning
propertyPressure, Temperature, SimTime, ForelinePressure or Thickness
minPressure, maxPressureValid pressure range in Torr. Bounds must be finite, nonnegative and increasing.
sourceFor ForelinePressure, the ID of a turbo that has a configured backing model.
<sensor address="104" chamber="Main" minPressure="1e-4" maxPressure="1e-2">cm</sensor>
<sensor address="108" chamber="Main" property="ForelinePressure" source="TP">pf</sensor>
<sensor address="400" chamber="Main" property="SimTime">simtime</sensor>
<sensor address="404" chamber="Main" property="Thickness">thk</sensor>

Put these sensor entries in a S7200Sensor section. Control needs matching device IDs and register addresses in its own hardware map. Keep the measurement-model attributes in HWConf.Emulator.xml.

Optional Turbo Backing Model

Turbo attributeMeaning
backingPumpID of the scroll pump. A missing pump is a load error.
forelineVolumeModeled foreline volume in liters; default 2.
forelineLimitPressure in Torr above which the model stops turbo pumping; default 5.

The model uses the backing pump's configured speed and ultimate pressure. The gate and foreline valve IDs must match the declared valves. These are virtual-model parameters, not equipment protection limits. Control interlocks must set the required start and gate-opening limits.

Note: Open the project folder in the Emulator. It reads HWConf.Emulator.xml and EmulatorConfig.xml from that folder. Reopen the project after edits. Do not copy emulator wiring over a production hardware profile.
