PLC Memory Map

The Sputter S7-200 PLC uses four memory areas: MB (marker bytes) for digital outputs, EB (input bytes) for digital inputs, DB1 (data block) for analog values, and PA (peripheral access). The emulator mirrors these areas. Addresses below come from the Sputter HWConf.Emulator.xml.

DB1 — Mass Flow Controllers

Setpoint AddressReadback AddressMFC
DB1:160DB1:164Ar1
DB1:168DB1:172N21

Setpoint and readback are both REAL (float32, 4 bytes). The emulator applies a first-order lag filter so that the readback ramps toward the setpoint over a few ticks.

DB1:17 — Turbo Pump Status Byte

One byte at DB1:17 encodes turbo pump state:

BitMeaning
1Running
2Accelerating
3At normal speed
4Rotation detected
5Alarm (not set during normal operation)
