Log Viewer Tab

The Log Viewer tab displays real-time log messages from the simulation engine, protocol servers, and device emulators.

Log Grid Columns

ColumnDescription
TimeTimestamp when the log entry was generated
LevelSeverity level (Debug, Info, Warning, Error)
SourceComponent that generated the message (e.g. S7Server, Engine, Physics)
MessageLog message text

Color Coding

Log rows are color-coded by severity level for quick visual scanning:

LevelColor
DebugDark blue
InfoDefault (light gray)
WarningYellow
ErrorRed

Filtering

Two filter controls narrow down the displayed log entries:

  • Source filter — dropdown listing all log sources. Select a specific source to show only messages from that component, or select All to show everything.
  • Level filter — minimum severity threshold:
    • Debug+ — show all messages
    • Info+ — show Info, Warning, and Error
    • Warning+ — show Warning and Error only
    • Error — show Error only

Controls

  • Auto-scroll checkbox — when enabled, the grid automatically scrolls to show the newest log entry. Disable to freeze the view while investigating a specific message.
  • Clear button — removes all current log entries from the grid.
Note: The log viewer retains a maximum of 5,000 rows. When this limit is reached, the oldest entries are removed as new ones arrive.
