Power Sources Tab

The Power Sources tab displays all emulated power supplies and their current state in a grid view.

Grid Columns

ColumnDescription
NameDevice name as defined in configuration (e.g. PSU1, PSU2)
PortCOM port or TCP endpoint the device is bound to
Link StatusConnection state between the emulator and the protocol layer
TypePower supply type (DC, Pulsed DC, RF)
VoltageOutput voltage in volts
CurrentOutput current in amps
PowerOutput power in watts
OutputOutput enable state (On/Off) — clickable to toggle

Link Status

The Link Status column indicates the health of each device connection:

StatusMeaning
OKVirtual COM port pair is open and communicating normally
Port DownThe emulator-side COM port could not be opened (port missing or in use)
No PeerThe emulator-side port is open but no client has connected to the other end of the pair
—TCP-based device — no COM port link status applies

Toggling Output

Click the Output cell for any power supply to toggle its output on or off. When output is enabled, the device will report non-zero voltage, current, and power values based on its configured setpoints. When output is disabled, all readings drop to zero.

This toggle simulates the front-panel output button on the physical power supply. The Control software can also enable/disable output via protocol commands, which will be reflected in the grid immediately.
